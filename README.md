# ポチマクロ (PochiMacro)

**マウス/キーボードの操作を記録して繰り返すマクロツール。Windows向け。**

追加パッケージなしで動きます（Python標準ライブラリのみ）。

</div>

---

## できること

- 🖱 **場所を順番に教える**: 対象アプリの①の場所にマウスを置いたまま数秒待つと覚え、
  次の場所へ動かせば②、③…と続けて登録できる。**クリックそのものを検知しない**ので、
  アンチチート等で入力監視がブロックされるゲームでも確実に使える
- ⏺ **操作を記録して繰り返す**: 記録開始してから実際に操作すると、**マウスの動きの軌跡**
  （通り道の座標と速さ）・クリック・キー入力を、長さの上限なくそのまま記録（対応して
  いないゲームもあります。そのときは上の「場所を順番に教える」を）
- 📍 各操作は画面上の座標を持てるので、実行時はその位置へカーソルを動かしてから押す
  （卵を孵化させ続けるような「決まった場所を押しつづける」作業向け。未登録ならいまの
  カーソル位置を押す）
- ✏️ 記録した操作は一覧であとから編集・削除・追加が可能（手動でも作れる）
- 📋 **マクロを複数保存して切り替え**: 用途ごとにマクロを作って、いつでも呼び出せる
- ⌨️ **グローバルホットキー**で入切（かまえる／ずっと実行／長押し／次のマクロへ切替／記録開始・終了）
- 🔁 くり返す**間隔・回数**を指定
- 🎯 対象アプリが最前面のときだけ動かす安全装置（既定オン）、右クリックでいつでも中断
- ⬆️ アプリ内更新（GitHub Releasesを確認してワンクリックで入れ替え）

### ⏺ 操作を記録 がゲーム中に拾えないとき

`⏺ 操作を記録` はキー/マウスの状態をポーリングして拾います。多くのアプリでは動きますが、
アンチチート（EasyAntiCheatなど）が入っているゲームは、対策として外部プロセスからの入力
観測そのものをブロックすることがあり、これはユーザーモードのプログラムからは回避できません。
そのときは **🖱 場所を順番に教える** を使ってください。クリックを検知するのではなく
「いまのマウス位置」を一定時間後に読むだけなので、ゲーム側の入力監視の影響を受けません。

## 使い方

```
python pochi_macro.py
```

もしくは [Releases](https://github.com/Simohayhe/pochi-macro/releases) から
`PochiMacro-x.y.z-setup.exe` を落として実行（インストーラ、管理者権限不要）。

**場所を順番に教える場合（ゲームなどでいちばん確実）**
1. 「🖱 場所を順番に教える」を押す
2. 対象アプリへ行って、①の場所にマウスを置いて数秒（待つ秒数で調整可）待つ
3. 続けて②、③…の場所へマウスを動かして、それぞれ数秒待つ
4. 覚え終わったら「■ やめる」

**実際の操作をそのまま記録する場合**
1. 「⏺ 操作を記録」を押すか、記録用ホットキー（既定 Ctrl+Shift+E）で記録を始める
2. **3秒待ってから実際に記録が始まる**ので、そのあいだに対象アプリへ切り替える
   （ボタンを押す動作そのものが記録に混ざらないようにするため）
3. 実際に操作する（マウスの動き・クリック・キー入力、すべて混在OK）
4. もう一度ボタンかホットキー、またはEscで記録終了（そのホットキー自体は記録されません）

**共通**
- 「間隔」「回数」を決めて、「▶ かまえる」（左クリック長押しで実行）／「▶ ずっと実行」／
  「⬇ 長押し」で開始
- 右クリック、またはもう一度ボタンを押すと停止

設定・マクロは `%APPDATA%\PochiMacro\config.json` に保存されます。

## ビルド

```
python tools/build.py
```

`dist/` に onefile exe・onedir版のzip・（Inno Setupが入っていれば）setup.exeを作ります。
