# ポチマクロ (PochiMacro)

**マウス/キーボードの操作を記録して繰り返すマクロツール。Windows向け。**

追加パッケージなしで動きます（Python標準ライブラリのみ）。

</div>

---

## できること

- ⏺ **一連の操作を記録して繰り返す**: 記録開始してから実際に操作すると、クリック・キー入力を
  順番どおり・長さの上限なしで記録。記録の開始/終了に使ったホットキー自体は記録されません
- 📍 **押す場所を登録**: マウス操作ごとに画面上の座標を持てるので、実行時はその位置へカーソルを
  動かしてから押す（卵を孵化させ続けるような「決まった場所を押しつづける」作業向け。
  未登録ならいまのカーソル位置を押す）
- ✏️ 記録した操作は一覧であとから編集・並べ替えなしで削除・追加が可能（手動でも作れる）
- 📋 **マクロを複数保存して切り替え**: 用途ごとにマクロを作って、いつでも呼び出せる
- ⌨️ **グローバルホットキー**で入切（かまえる／ずっと実行／長押し／次のマクロへ切替／記録開始・終了）
- 🔁 くり返す**間隔・回数**を指定
- 🎯 対象アプリが最前面のときだけ動かす安全装置（既定オン）、右クリックでいつでも中断
- ⬆️ アプリ内更新（GitHub Releasesを確認してワンクリックで入れ替え）

### 記録がゲーム中に拾えないとき

記録はキー/マウスの状態を直接ポーリングする方式なので、ふつうは対象アプリが管理者権限で
動いていても拾えます。それでも拾えない場合は、ポチマクロ側も管理者権限で起動してみてください
（対象アプリより低い権限では、Windowsのしくみ上まれに入力が見えないことがあります）。

## 使い方

```
python pochi_macro.py
```

もしくは [Releases](https://github.com/Simohayhe/pochi-macro/releases) から
`PochiMacro-x.y.z-setup.exe` を落として実行（インストーラ、管理者権限不要）。

1. 「⏺ 記録開始」を押すか、記録用ホットキー（既定 Ctrl+Shift+E）で記録を始める
2. 対象アプリへ行って、実際に操作する（クリック・キー入力・両方混在OK）
3. もう一度ボタンかホットキー、またはEscで記録終了
4. 「間隔」「回数」を決めて、「▶ かまえる」（左クリック長押しで実行）／「▶ ずっと実行」／
   「⬇ 長押し」で開始
5. 右クリック、またはもう一度ボタンを押すと停止

設定・マクロは `%APPDATA%\PochiMacro\config.json` に保存されます。

## ビルド

```
python tools/build.py
```

`dist/` に onefile exe・onedir版のzip・（Inno Setupが入っていれば）setup.exeを作ります。
